# torrent-metadata-toolkit

[![CI](https://github.com/cancelpt/torrent-metadata-toolkit/actions/workflows/ci.yml/badge.svg)](https://github.com/cancelpt/torrent-metadata-toolkit/actions/workflows/ci.yml)

[简体中文](README.zh-CN.md)

Utilities for reading, updating, and exporting `.torrent` metadata.

## Features

- Parse single-file and multi-file torrent metadata.
- Read core fields: `info_hash`, `announce`, `trackers`, `piece_length`, `piece_count`, etc.
- Mutate metadata in memory (`comment`, `source`, `private`, trackers, and more).
- Export with structured options (`ExportOptions`) and structured results (`ExportResult`).
- Customize tracker merge and output naming through strategy objects.

## Requirements

- Python 3.8+

## Quick Start

```python
from torrent_metadata_toolkit import ExportOptions, TorrentFile, export_as_torrent

source = TorrentFile("tests/fixtures/bbc7141d3e897160b9afd24f5bbf022580ec2978.torrent")

result = export_as_torrent(
    source.torrent_data,
    ExportOptions(
        trackers=[
            "udp://tracker.opentrackr.org:1337/announce",
            "http://tracker.example.com/announce",
        ],
        source="my-tool",
        comment="generated by script",
        private=False,
        created_by="my-tool/1.0",
        output_dir="tmp",
    ),
)

print(result.success)
print(result.output_name)
print(result.output_path)
print(result.torrent.trackers)
```

If you only want to change trackers and keep all other metadata untouched:

```python
result = export_as_torrent(
    source.torrent_data,
    ExportOptions(
        trackers=["http://tracker.example.com/announce"],
        output_dir="tmp",
    ),
)
```

BT quick export preset:

```python
from torrent_metadata_toolkit import ExportOptions, export_as_torrent

result = export_as_torrent(
    source.torrent_data,
    ExportOptions.bt_seed(
        trackers=["http://tracker.example.com/announce"],
        output_dir="tmp",
    ),
)
```

One-step helper API:

```python
from torrent_metadata_toolkit import export_as_bt_torrent

result = export_as_bt_torrent(
    source.torrent_data,
    ["http://tracker.example.com/announce"],
    output_dir="tmp",
)
```

## Advanced Export Strategy

```python
from torrent_metadata_toolkit import (
    AppendUniqueTrackers,
    ExportOptions,
    TorrentExportService,
    TorrentFile,
)

source = TorrentFile("tests/fixtures/bbc7141d3e897160b9afd24f5bbf022580ec2978.torrent")
service = TorrentExportService(tracker_strategy=AppendUniqueTrackers())

result = service.export(
    source.torrent_data,
    ExportOptions(trackers=["http://tracker.example.com/announce"], output_dir="tmp"),
)

print(result.torrent.trackers_count)
```

## API Notes

### `TorrentFile`

Create an instance from:

- a file path (`str`) to a `.torrent` file, or
- a decoded torrent dictionary.

Common attributes:

- `file_name`
- `info_hash`
- `announce`
- `trackers` / `trackers_count`
- `piece_length` / `piece_count`
- `comment`, `source`, `created_by`, `creation_date`

Common mutators:

- `change_announce(...)`
- `add_trackers(...)`
- `change_comment(...)`
- `change_source(...)`
- `change_private(...)`
- `save(path)`

### `ExportOptions`

Parameter object controlling export behavior:

- metadata fields (`source`, `comment`, `private`, `created_by`, `creation_date`)
- tracker input (`trackers`)
- output control (`output_name`, `output_dir`)

### `ExportResult`

Export return object:

- `success: bool`
- `output_name: str`
- `output_path: str`
- `torrent: TorrentFile`

### `TorrentExportService`

Application service for exporting torrents with configurable strategies:

- tracker strategy: `ReplaceTrackers` (default) or `AppendUniqueTrackers`
- naming strategy: `DefaultOutputNameStrategy`

### `export_as_torrent(...)`

Facade helper:

- input: `(torrent_data, options, service=None)`
- output: `ExportResult`
