# torrent-metadata-toolkit

[![CI](https://github.com/cancelpt/torrent-metadata-toolkit/actions/workflows/ci.yml/badge.svg)](https://github.com/cancelpt/torrent-metadata-toolkit/actions/workflows/ci.yml)

[English](README.md)

用于读取、修改和导出 `.torrent` 元数据的工具库。

## 功能特性

- 解析单文件和多文件种子元数据。
- 读取核心字段：`info_hash`、`announce`、`trackers`、`piece_length`、`piece_count` 等。
- 在内存中修改元数据（`comment`、`source`、`private`、`trackers` 等）。
- 使用结构化参数（`ExportOptions`）和结构化结果（`ExportResult`）进行导出。
- 通过策略对象自定义 tracker 合并逻辑和输出文件命名逻辑。

## 环境要求

- Python 3.8+

## 快速开始

```python
from torrent_metadata_toolkit import ExportOptions, TorrentFile, export_as_torrent

source = TorrentFile("tests/fixtures/bbc7141d3e897160b9afd24f5bbf022580ec2978.torrent")

result = export_as_torrent(
    source.torrent_data,
    ExportOptions(
        trackers=[
            "udp://tracker.opentrackr.org:1337/announce",
            "http://tracker.example.com/announce",
        ],
        source="my-tool",
        comment="generated by script",
        private=False,
        created_by="my-tool/1.0",
        output_dir="tmp",
    ),
)

print(result.success)
print(result.output_name)
print(result.output_path)
print(result.torrent.trackers)
```

如果你只想修改 tracker，其他元数据保持不变：

```python
result = export_as_torrent(
    source.torrent_data,
    ExportOptions(
        trackers=["http://tracker.example.com/announce"],
        output_dir="tmp",
    ),
)
```

BT 快捷导出预设：

```python
from torrent_metadata_toolkit import ExportOptions, export_as_torrent

result = export_as_torrent(
    source.torrent_data,
    ExportOptions.bt_seed(
        trackers=["http://tracker.example.com/announce"],
        output_dir="tmp",
    ),
)
```

一步式快捷 API：

```python
from torrent_metadata_toolkit import export_as_bt_torrent

result = export_as_bt_torrent(
    source.torrent_data,
    ["http://tracker.example.com/announce"],
    output_dir="tmp",
)
```

## 高级导出策略

```python
from torrent_metadata_toolkit import (
    AppendUniqueTrackers,
    ExportOptions,
    TorrentExportService,
    TorrentFile,
)

source = TorrentFile("tests/fixtures/bbc7141d3e897160b9afd24f5bbf022580ec2978.torrent")
service = TorrentExportService(tracker_strategy=AppendUniqueTrackers())

result = service.export(
    source.torrent_data,
    ExportOptions(trackers=["http://tracker.example.com/announce"], output_dir="tmp"),
)

print(result.torrent.trackers_count)
```

## API 说明

### `TorrentFile`

可通过以下方式创建实例：

- 传入 `.torrent` 文件路径（`str`）
- 传入已解码的种子字典

常用属性：

- `file_name`
- `info_hash`
- `announce`
- `trackers` / `trackers_count`
- `piece_length` / `piece_count`
- `comment`、`source`、`created_by`、`creation_date`

常用修改方法：

- `change_announce(...)`
- `add_trackers(...)`
- `change_comment(...)`
- `change_source(...)`
- `change_private(...)`
- `save(path)`

### `ExportOptions`

用于控制导出行为的参数对象：

- 元数据字段（`source`、`comment`、`private`、`created_by`、`creation_date`）
- tracker 输入（`trackers`）
- 输出控制（`output_name`、`output_dir`）

### `ExportResult`

导出结果对象：

- `success: bool`
- `output_name: str`
- `output_path: str`
- `torrent: TorrentFile`

### `TorrentExportService`

支持策略注入的导出服务：

- tracker 策略：`ReplaceTrackers`（默认）或 `AppendUniqueTrackers`
- 命名策略：`DefaultOutputNameStrategy`

### `export_as_torrent(...)`

门面函数：

- 输入：`(torrent_data, options, service=None)`
- 输出：`ExportResult`
